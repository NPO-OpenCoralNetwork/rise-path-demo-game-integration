変数とメモリ管理

Pythonの変数は「箱」ではなく「名札」。この違いが、AIが書いたコードのバグを見抜く力になります。

⏱ 12分初級前提：0-3 Pythonを動かす

このレッスンでできるようになること

  • 変数が「オブジェクトを指す名札」であることを説明できる
  • b = a と a.copy() の違いをコードで示せる
  • ミュータブルな値をうっかり共有するバグに気づける

02参照とコピー

Pythonで b = a と書いても、リストは複製されません。 b は、a と同じにもう一枚名札を貼っただけです。

🏷️
たとえるなら

同じ1冊のノートに「あなたのノート」「わたしのノート」という付箋を2枚貼った状態。どちらの付箋から開いて書き込んでも、ノートは1冊です。

copy_vs_ref.pypython
1a = [1, 2, 3]2b = a            # 名札をもう1枚3c = a.copy()     # 中身を複製45b.append(4)6print(a)  7print(c)
出力
[1, 2, 3, 4]
[1, 2, 3]
◎ 確認しよう · 1/2
次のコードの後、x の中身はどうなる？　x = [0]; y = x; y[0] = 9
おしい！　y = x はリストを複製しません。上の図 2-1 の a と b と同じ関係です。
💬 AIへの指示テンプレート
この関数で リスト名 を変更すると、呼び出し元のデータまで変わってしまいます。コピーが必要な箇所を指摘し、copy / deepcopy のどちらを使うべきか理由とともに修正してください。

まとめ

  1. 変数は値の「箱」ではなく、オブジェクトを指す「名札」。
  2. b = a は名札を増やすだけ。複製は copy()。
  3. リストや辞書（ミュータブル）は共有に注意。
