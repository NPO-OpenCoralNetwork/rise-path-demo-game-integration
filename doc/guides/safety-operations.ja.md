# AI の安全の運用ガイド（オーナーと拠点のスタッフ向け）

- 更新日: 2026-10-22
- 対象: Rise Path のオーナーと、子ども食堂などの拠点で学習者を手伝うスタッフ
- 関連: 決定の記録 [../brushup-2026/ai-access-plan.ja.md](../brushup-2026/ai-access-plan.ja.md) の 4 章、データの一覧 [../legal/ai-data-inventory.ja.md](../legal/ai-data-inventory.ja.md)

このガイドは、Phase 0.5（未成年のための安全対策）で入った仕組みを、毎日の運用で使うための手引きです。コードの場所は `ファイル:行` で書いています。行番号は 2026-10-22 時点の作業ツリーのものです。

> **命に関わる緊急のときは、このガイドを読むより先に 110（警察）か 119（救急・消防）に電話してください。** 子どもが虐待を受けているかもしれないときは 189（児童相談所虐待対応ダイヤル）です。くわしくは 7 章を見てください。

## 1. 仕組みのあらまし

| 仕組み | 中身 |
|---|---|
| 年齢の登録 | AI を使う前に、生まれた**年と月**を 1 回だけ登録します（日は聞きません）。年齢は日本時間で毎回計算し、誕生日は「生まれた月の最後の日」とみなします（若い側に丸めます）。18 歳未満が「未成年」です（`server/safety/age.js:65-83`）。登録していない人は AI を使えません。AI を使わない学習はそのまま使えます |
| 保護者の同意 | 18 歳未満は、保護者の同意を記録するまで AI を使えません。同意の取り方は 2 つです。(a) 学習者の端末の画面で保護者が同意する、(b) 紙の同意書を受け取り、管理者が記録する。保護者の名前は記録しません。同意はいつでも取り消せ、取り消すと AI はすぐ止まります（`server/safety/access.js`） |
| 子ども向けの指示 | 18 歳未満が AI を使うとき、AI への指示（システムプロンプト）に子どもの安全のルールを足します（`server/llm/prompts/shared.js` の `MINOR_SAFETY`） |
| 入力と答えの確認 | 18 歳未満の入力は、まずサーバーの中の簡単なチェック（本人のことと読めるつらい気持ちの言葉、電話番号・メールアドレス・住所）にかけ、次に Claude で確かめます。AI の答えも、見せる前に Claude で確かめます。チューターの答えは、確認が終わってからまとめて届きます（`server/safety/prefilter.js`、`server/safety/moderation.js`、`server/routes/llm.js`） |
| 確認できないときは止める | 確認の AI がエラーになった、断った、本番なのに模擬（モック）の AI で動こうとした、入力が長すぎて 1 回の確認に入らない、のどれでも、18 歳未満の AI は止めます（`server/safety/moderation.js:270-294`、`:355-373`） |
| その日のお休み | 1 人が 1 日（日本時間）に `SAFETY_BLOCKS_BEFORE_PAUSE` 回（既定 10 回）入力を止められると、その人の AI は日本時間の 0 時までお休みになります。つらい気持ちで相談先を出した回と、個人情報（分類「個人情報」）で止めた回は数えません（`server/safety/access.js:184-199`、`:217-223`） |
| 報告 | ログインしている人は誰でも、AI の答えの横の「報告する」から、おかしな答えを知らせられます。1 人 1 日 20 件まで（`server/routes/safety.js`） |
| 通知 | 新しい報告、相談先の表示、止めた答え、確認の失敗、お休みの開始を、運営のチャット（Slack など）に知らせられます。学習者の文章は送りません（`server/safety/events.js`） |

18 歳以上の人は、年齢の登録だけで使えます。入力と答えの確認はしません。AI であることの表示と報告ボタンは、全員に出ます。

ログインしていない人（ゲスト）は、AI を使えません。環境変数 `LLM_GUEST_AI` をちょうど `true` にしたときだけ使えますが、そのときゲストは大人として扱われます。18 歳未満が使う環境では設定しないでください（`server/middleware/aiAccessGate.js:44-45`、`:71-75`）。

## 2. 管理者にする・外す（オーナー）

管理者は、報告の文章（子どもが書いた質問をふくむことがあります）を読めます。**管理者は必要な人だけ、少人数にしてください。**

### 2.1 管理者にする

1. 管理者にする人が、`https://app.<domain>` で一度ログインし、設定画面（`/settings`）を開きます。ここでプロフィールの行が作られます。
2. VM で次を流します（`deploy/risepath-vm/README.md:187-197` と同じ手順です）。

```bash
cd /opt/risepath/deploy/risepath-vm
docker compose --env-file stack.env exec db psql -U risepath_app -d risepath \
  -c "UPDATE user_profiles SET role='admin' WHERE user_id='<Supabase の user id>'"
```

3. `UPDATE 1` と出れば成功です。ページを読み込み直すと、設定画面の「AI と安全」に「安全の管理」が出ます。

user id は、Supabase ダッシュボードの Authentication → Users に出る UID です。

### 2.2 管理者を外す

```bash
docker compose --env-file stack.env exec db psql -U risepath_app -d risepath \
  -c "UPDATE user_profiles SET role='learner' WHERE user_id='<Supabase の user id>'"
```

管理者かどうかは、サーバーがリクエストのたびにデータベースで確かめます。外すと、次の操作からすぐ使えなくなります（`server/middleware/requireAdmin.js:15-41`）。スタッフが辞めたとき、拠点の担当が変わったときは、その日のうちに外してください。

## 3. 安全の管理のページを読む

設定 →「AI と安全」→「安全の管理」（`/settings/admin/safety`）を開きます。管理者でない人には「このページは管理者だけが使えます。」と出ます。

### 3.1 集計

期間（直近 7・30・90・365 日）を選ぶと、記録の件数が出ます。**集計には学習者の文章は出ません。**

| 種類（画面の表示） | 意味 | 見たときにすること |
|---|---|---|
| 入力を止めた | 18 歳未満の入力が、ルールに合わずに止まった | 分類を見ます。「個人情報」が多ければ、拠点で「名前や電話番号を AI に書かない」ことをもう一度伝えます |
| 答えを止めた | AI の答えが、子どもに見せる前に止まった | 同じ機能・同じレッスンで続くなら、そのレッスンの内容や AI の指示に問題がないか、開発の担当に伝えます |
| 相談先を表示 | 入力に、つらい気持ち・自分を傷つけること・虐待・いじめの言葉があり、AI の代わりに相談窓口を出した | **件数が出たら、見守りを強めるきっかけにします。** 集計には誰かは出ません（通知には学習者の ID の先頭 8 文字が出ます）。7 章を読んでください |
| 確認できず停止 | 確認の AI が使えず、18 歳未満の AI を止めた | 続くなら、`ANTHROPIC_API_KEY`、Anthropic の障害、API のログ（`[AI safety] safety check failed`）を確かめます。10 章を見てください |
| 報告 | 学習者からの報告 | 4 章 |

分類の意味: 自傷（self_harm）、性的（sexual）、暴力（violence）、いじめ（bullying）、個人情報（personal_info）、危険（dangerous）、差別（hate）、その他（other）。「対象」は 18 歳以上か 18 歳未満かです。

### 3.2 記録に残すもの・残さないもの

- 止めた入力・止めた答え・相談先の表示・確認の失敗: 日時、学習者の ID、機能、分類、対象だけを残します。**学習者の文章も AI の答えも残しません**（`server/safety/events.js:155-163`）。
- 報告: 報告した人が送った文章（AI の答え 4,000 字まで、質問 2,000 字まで、ひとこと 500 字まで）と、レッスンの場所を残します。

## 4. 報告を確かめる

「報告」の欄で「未確認」を選ぶと、新しい順に出ます。1 件ごとに、理由、AI の答え、質問、ひとこと、場所、学習者の ID、対象（18 歳以上・未満）が出ます。

1. 理由と AI の答えを読みます。
   - **まちがっている**: レッスンの内容に関わるなら、教材の担当に伝えます。
   - **こわい・いやな気持ちになる・あぶない／子どもに向いていない**: どの機能で起きたかを見ます。18 歳未満で起きたなら、確認をすり抜けた答えです。開発の担当に、機能と日時を伝えます（文章を写して渡すのは必要な部分だけにします）。
   - **質問やひとことに、子どもの困りごとや危険が書かれている**: 7 章の手順に進みます。
2. 対応が終わったら「確認済みにする」を押します。誰がいつ確認したかが残ります（`server/routes/adminSafety.js:167-184`）。
3. 報告した子どもに直接お礼を言う必要はありません。画面には「送りました。教えてくれて、ありがとうございます。」と出ています。

**報告の文章は 90 日で消えます。** 90 日を過ぎた報告は「90日を過ぎたため、文章は消しました。」と出ます。あとで必要になりそうな報告（7 章の件など）は、90 日のうちに対応を終えてください。報告の文章を、チャットやメールに貼り付けて広めないでください。

## 5. 年齢を登録する・直す

学習者は、自分で年と月を **1 回だけ** 登録できます。まちがえたときや、子どもが自分で登録できないときは、管理者が登録します。

1. 学習者の端末で「設定」→「AI の利用設定」を開き、いちばん下の「スタッフに見せる番号」を見せてもらいます。「番号をぜんぶコピー」も使えます。
2. 管理者の「安全の管理」→「学習者の AI の利用設定」に、その番号を **ぜんぶ（36 文字）** 入れて「調べる」を押します。
3. 「生まれた年と月を登録する」（すでにあるときは「直す」）で年と月を選び、「確認のしかた」を選びます。
   - **保護者からの申告**: 保護者から聞いた年月です。
   - **スタッフが確認**: スタッフが書類などで確かめた年月です。
4. 「年月を登録する」を押します。

注意:

- 18 歳以上を 18 歳未満に直すと、その学習者は保護者の同意を記録するまで AI を使えなくなります。
- 18 歳の誕生日を迎えた月の最後の日（日本時間）からは、自動で 18 歳以上として扱われます。保護者の同意の記録は残りますが、使われなくなります。
- 年齢の登録は、本人や保護者の申告です。身分証の確認はしていません。

## 6. 紙の同意書を記録する

学習者の端末で保護者が同意できないとき（保護者が拠点に来られない、など）は、紙の同意書を使います。

### 6.1 同意書を用意する（オーナー）

画面の同意の文と**同じ内容**の紙を用意してください。今の版は **`guardian-ai-2026-10`** です（`server/safety/access.js:30`）。画面の文は `components/safety/AiAccessSetupView.tsx` の「保護者の方へ：AI 機能を使うことへの同意」にあります。少なくとも次をふくめます。

- AI 機能でできること（AI 先生、作文フィードバック、診断の解説、コースづくり）と、AI の答えはまちがえることがあること
- 送られるデータ: 入力した文章と関係するレッスンの文章を、Anthropic 社（アメリカ）に送ること。18 歳未満は答えを確かめるためにも送ること。名前やメールアドレスは送らず、アカウントからつくった元に戻せない記号だけを送ること。Anthropic 社は送った内容を AI の学習に使わないこと
- お子さまを守るしくみ（子ども向けの指示、入力と答えの確認、相談窓口の表示、その日のお休み、報告）
- 記録すること: 生まれた年と月、同意の日時・続柄・方法。止めた入力の記録（文章はふくまない）は 1 年、報告の文章は 90 日で消すこと
- 同意のやめ方（画面から、またはスタッフに伝える）
- 同意文の版（`guardian-ai-2026-10`）、お子さまのアカウントの番号を書く欄、続柄（親・親以外の保護者・その他の養育者）、日付、保護者の署名

【要記入: 同意書の様式と、受け取った紙を保管する場所・保管する期間・捨て方】。紙には保護者の名前と署名が残ります。鍵のかかる場所に保管し、見る人を限ってください。

### 6.2 記録する（管理者）

1. 署名された紙を受け取り、番号・版・続柄・日付・署名がそろっているか確かめます。
2. 5 章と同じように、学習者の番号で「調べる」を押します。年月が未登録なら、先に登録します（同意は 18 歳未満にだけ記録できます）。
3. 「紙の同意書を記録する」で続柄を選び、「署名された紙の同意書を確認しました。」にチェックを入れて「同意を記録する」を押します。
4. 方法は「紙の同意書（スタッフが記録）」、記録した人は押した管理者として残ります（`server/routes/adminSafety.js:238-261`）。保護者の名前はアプリに入れません。

### 6.3 取り消す

保護者から「やめたい」と言われたら、同じ画面の「同意を取り消す」を押します。その学習者の AI はすぐ止まります。学習者の端末の「AI の利用設定」からも取り消せます。

### 6.4 同意文を変えるとき（オーナー）

同意は版ごとに記録しています。同意の文を変えて版（`CONSENT_POLICY_VERSION`）を上げると、**18 歳未満の全員が、新しい版で同意し直すまで AI を使えなくなります**（`server/safety/access.js:172-182`）。版を上げる前に、拠点への案内と紙の同意書の準備をしてください。版はサーバー（`server/safety/access.js:30`）と画面（`services/aiAccessRules.ts:7`）の 2 か所にあり、同時に変えます。

## 7. 虐待や命の危険が疑われる報告・相談先の表示があったとき

AI は、子どもの状況を判断できません。仕組みが知らせるのは「きっかけ」だけです。判断と対応は人が行います。

### 7.1 すぐにすること

1. **命に関わる危険が今ありそうなら、すぐに 110（警察）か 119（救急・消防）に電話します。**
2. **虐待を受けているかもしれないと思ったら、189（児童相談所虐待対応ダイヤル）に電話します。** 189 は、虐待かもと思ったときに、すぐに児童相談所に通告・相談ができる全国共通の番号です（こども家庭庁 <https://kodomoshien.cfa.go.jp/no-gyakutai/189/>）。法律は「児童虐待を受けたと思われる児童を発見した者は、速やかに」市町村・福祉事務所・児童相談所に通告しなければならないと定めています。確かな証拠は要りません。守秘義務の決まりは、この通告をさまたげないとされています（児童虐待の防止等に関する法律 第 6 条第 1 項・第 3 項 <https://laws.e-gov.go.jp/law/412AC1000000082>）。
3. 拠点の責任者と、オーナーに伝えます。【要記入: 拠点ごとの連絡先と、夜間・休日の連絡の順番】

### 7.2 そのあとにすること

- 子どもがわかる場合（拠点で使っているアカウントなど）は、拠点のスタッフが、いつもの見守りの中で声をかけます。AI とのやりとりを責めたり、問い詰めたりしないでください。アプリのメッセージで連絡はしません。
- アプリには子どもの名前は入っていません。学習者の ID と、拠点での利用の記録から、誰のアカウントかを確かめられるのは、拠点の責任者だけにします。
- 関係機関（警察、児童相談所など）に情報を伝えるのは、法令に基づく場合や、命や体を守るために必要で本人の同意を得るのが難しい場合、子どもの健全な育成のために特に必要で本人の同意を得るのが難しい場合です（個人情報保護法 第 27 条第 1 項第 1〜3 号 <https://laws.e-gov.go.jp/law/415AC0000000057>）。伝えたことは、日時・相手・内容の要点を、アプリの外の決められた場所に記録します。【要記入: 記録の場所】【要確認: 拠点ごとの対応手順を専門家と決める】
- 報告の文章は 90 日で消えます。関係機関から求められそうな場合は、その前に必要な部分だけを、決められた場所に控えます。
- 対応が終わったら、その報告を「確認済み」にします。

## 8. 報告を見てよい人と、データの扱い

- 報告の文章を見られるのは、管理者だけです（`server.js` の `/api/v2/admin` は `requireAuth` と `requireAdmin` のあとにあります）。集計には文章は出ません。
- 通知（Slack など）には、学習者の文章は入りません。入るのは、種類、機能、分類、対象と、学習者の ID の先頭 8 文字だけです（`server/safety/events.js:164-165`、`:181-189`）。それでも、通知を受けるチャンネルは非公開にし、入る人を管理者に限ってください。
- 通知は、同じ種類なら 1 分に 1 回までです。そのあいだに起きた件数は、次の通知に「(+N more …)」として足されます。
- 報告の文章や学習者の ID を、管理のページの外（チャット、メール、表計算など）に写さないでください。7 章の場合だけ、必要な部分を決められた場所に控えます。

## 9. 保存期間

| データ | 保存期間 | 消し方 |
|---|---|---|
| 報告の文章（AI の答え、質問、ひとこと、場所） | 90 日 | 90 日を過ぎると文章を消し、報告があったこと（日時・理由・機能）だけを残します |
| 止めた入力・止めた答え・相談先の表示・確認の失敗・報告の記録 | 365 日 | 365 日を過ぎると記録ごと消します |
| 生まれた年と月 | アカウントがあるあいだ | アカウントを消すと一緒に消えます（今はアプリ内にアカウント削除の機能はありません） |
| 保護者の同意の記録（日時・続柄・方法・記録した管理者・取り消した日時） | アカウントがあるあいだ | 取り消しても記録は残します（いつ同意し、いつやめたかの証拠のため）。アカウントを消すと一緒に消えます |
| 紙の同意書 | 【要記入】 | 【要記入】 |

古い記録を消す処理は、記録が増えたときや管理者が安全のページを開いたときに、1 つのサーバーで 1 時間に 1 回まで動きます（`server/safety/events.js:124-142`）。だれも使わない期間が続くと、消すのが少し遅れることがあります。

アカウントが消えたとき、安全の記録の学習者 ID は空になり、件数だけが残ります。ログインした人の記録は学習者 ID の欄だけで人とつながり、ほかの欄（`subject`）に ID の写しは持たないので、消したあとに ID は残りません（`subject` に入るのはゲストの IP アドレスの部分だけです）（`server/migrations/014_minor_safeguards.sql:54-55`、`server/safety/events.js:65`）。

## 10. 設定（環境変数）

VM では `deploy/risepath-vm/stack.env` に書きます（例: `deploy/risepath-vm/stack.env.example`）。

| 名前 | 既定 | 中身 |
|---|---|---|
| `LLM_GUEST_AI` | 未設定（ゲストは AI を使えない） | ちょうど `true` のときだけ、ログインしていない人が AI を使えます（大人として扱います）。18 歳未満が使う環境では設定しません |
| `SAFETY_BLOCKS_BEFORE_PAUSE` | 10 | 1 日に何回入力を止められたら、その日の AI をお休みにするか（相談先を出した回と、個人情報で止めた回は数えません）。0 にするとお休みにしません |
| `SAFETY_ALERT_WEBHOOK_URL` | 未設定（`AI_CAP_ALERT_WEBHOOK_URL` を使う） | 安全の通知を送る Slack や Discord の Incoming Webhook。`https://` だけ。URL は秘密の値です |
| `AI_ACCESS_DEV_AUDIENCE` | 未設定 | 開発用。本番（`NODE_ENV=production`）では無視し、設定されていると起動時に警告を出します。VM では設定しません |

## 11. 困ったとき

| 起きていること | 確かめること |
|---|---|
| 18 歳未満の全員の AI が「確認できず停止」になる | `ANTHROPIC_API_KEY` が入っているか。`LLM_PROVIDER=mock`、`LLM_MOCK_FALLBACK=true`、`LLM_TASK_SAFETY_SCREEN` を設定していないか（本番で模擬の AI に回ると止めます）。Anthropic の障害情報 |
| 全員の AI が使えない（API が 503 `ai_access_unavailable` を返す） | データベースが動いているか（`docker compose --env-file stack.env ps`） |
| 安全のページで「サーバーで管理者として確認できませんでした。」と出る | 2 章の `UPDATE` が当たっているか |
| 子どもが「今日は AI がお休み」と言う | 止められた入力が 1 日の回数に達しています。画面から解除するボタンはありません。日本時間の 0 時に戻ります。止められた理由が誤りだと思うときは、集計の分類を見て、開発の担当に伝えます。子どもを責めないでください（画面にも「責めているのではありません」と出ています） |
| 子どもが年月をまちがえて登録した | 5 章の手順で管理者が直します |
