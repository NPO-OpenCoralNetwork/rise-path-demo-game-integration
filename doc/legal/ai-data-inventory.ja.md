## この一覧の前提（Phase 0 と Phase 0.5 のあとの状態）

この一覧は、Phase 0 と Phase 0.5 の変更を入れたあとの状態を書いています。変更前とのちがいは次のとおりです。

- **Gemini（Google の AI）は使いません。** 環境変数 `GEMINI_ALLOWED` がちょうど `"true"` のときだけ使います。未設定やほかの値なら、`GEMINI_API_KEY` があっても使いません（`server/llm/models.config.js:25`）。Gemini API の追加規約が、18 歳未満が使う、または使う可能性が高いサービスでの利用を禁じているためです（<https://ai.google.dev/gemini-api/terms>、2026-04-28 更新）。
- **AI チューター・作文フィードバック・コース生成は、安いモデル（Claude Haiku 5.5）で動きます**（`server/llm/models.config.js:93-94`、`:102`）。
- **共有 Hermes エージェント（AI コーチのチャット）は学習者に出しません**（`config/features.ts:50`、`App.tsx:331`、`App.tsx:439`）。
- **Memanto（AI メモリ）は既定で止まっています**（`deploy/risepath-vm/stack.env.example`）。
- **AI を使えるのは、ログインして生まれた年と月を登録した人だけです。18 歳未満は、保護者の同意の記録も要ります**（Phase 0.5。`server/middleware/aiAccessGate.js:68-100`、`server/safety/access.js`）。ログインしていない人（ゲスト）は、環境変数 `LLM_GUEST_AI` をちょうど `"true"` にしたときだけ AI を使えます。既定では使えません（`server/middleware/aiAccessGate.js:44-45`）。
- **18 歳未満の AI の入力と答えは、見せる前に Claude で確かめます**（下の「安全の確認」の行）。そのため、18 歳未満の文章は Anthropic に 2 回送られます。
- **ログインした人の AI の呼び出しには、元に戻せない記号（仮の ID）を付けて送ります**（下の「Anthropic に送る利用者の記号」の行）。名前・メールアドレス・アカウント ID そのものは送りません。
- **ログインした人のレッスンの進み具合を、Rise Path のサーバーにも保存します**（Phase 2。下の「レッスンの進み具合」の行）。前は、その端末のブラウザの中だけでした。外部の会社には送りません。
- **有料のサポータープラン（Phase 3）は、作りましたが止めています。** 動かすと、決済サービス Stripe にアカウント ID を送り、お支払いの記録を Rise Path の DB に残します（下の「有料プランの決済」と「有料プランのお支払いの記録」の行）。今は Stripe のテストモードで、オーナーが決めたテストの方だけが使えます。お金は動きません。
- **アカウントを削除できます（Phase 4）。ただし、画面からの削除は、はじめ止まっています。** オーナーが API の `ACCOUNT_DELETION_ENABLED=true` にすると（[../brushup-2026/ai-access-plan.ja.md](../brushup-2026/ai-access-plan.ja.md) の 8.2 の 2 と 3 のあと）、設定の「アカウントを削除する」から、パスワードを入れて、すぐに Rise Path のデータを消します。止まっているあいだは、連絡を受けたスタッフが消します（`scripts/delete-account-data.mjs`）。Nexloom と P-School と共通のログインは残ります。削除のあとも残すものは、下の「アカウントを削除した記録」などの行と、それぞれの行の「保存期間」に書いています（`server/services/accountDeletion.js`）。
- **期限が来た記録を、1 時間ごとに消します（Phase 4）。** `server/services/retention.js`。使っていないアカウントは、自動では消しません。
- **XP・バッジ・連続記録は、サーバーの記録から数えます（Phase 5）。** 前は、ブラウザの中の学習の履歴などから計算していました。ログインした人の XP の記録と、学んだ日（日付だけ）を Rise Path の DB に保存します（下の「XP・バッジ・学んだ日」の行）。外部には送りません。AI アプリからも読めません。
- **学習の履歴（レッスンの題名をふくむ）は、Phase 2 より前からサーバーに送っています**（下の「学習の履歴」の行）。前の版のこの一覧は「進み具合は外部に送らない（ブラウザの中だけ）」とだけ書いていましたが、ログインした人がレッスンを始めたこと・終えたことの記録は、題名といっしょにサーバーに送っていました。

行番号は 2026-10-22 時点の作業ツリーのものです（Phase 2 で足した・直した行は 2026-10-23 時点）。コードが変わると行がずれることがあります。

## 用語

- **API**: プログラム同士がデータをやり取りする窓口です。ここでは、Rise Path のサーバーが AI の会社にデータを送る経路を指します。
- **プロンプト**: AI に渡す文章（指示と材料）です。
- **埋め込み（embedding）**: 文章を数字の列に変えて、意味の近さで検索できるようにする処理です。
- **MCP**: AI アプリが外部のツールやデータにつながるための共通の決まりごとです。

## 気をつける点

1. **生活記録には健康に近い情報があります。** 睡眠、運動、飲酒、体調メモなどです（`server/migrations/006_life_journal.sql:23-41`）。体調メモに病気のことが書かれると、個人情報保護法の「要配慮個人情報」（病歴など）にあたる場合があります。取得には原則として本人の同意が要ります（個人情報保護法 第 20 条第 2 項、<https://laws.e-gov.go.jp/law/415AC0000000057>）。扱い方は【要確認】です。
2. **Anthropic へは米国の会社への送信です。** 個人情報保護法 第 28 条（外国にある第三者への提供）の手続きが要ります。詳しくはプライバシーポリシーの下書きの「外国への移転」を見てください。
3. **Vercel・Cloudflare・Google Cloud は「預けるだけ」かもしれません。** 事業者が個人データを取り扱わない契約になっていれば、第三者提供にも委託にもあたらないとされています（個人情報保護委員会 Q&A 7-53、<https://www.ppc.go.jp/all_faq_index/faq1-q7-53/>）。各社の契約がそうなっているかは【要確認】です。
4. **AI の会社には、名前やメールアドレスを送らない作りです。** ただし、学習者が質問や作文に自分で個人情報を書けば、それは送られます（18 歳以上の場合）。18 歳未満の入力は、携帯電話の番号・メールアドレス・住所をサーバーで見つけたら、AI に送らずに止めます（`server/safety/prefilter.js`）。見つけられない書き方もあるので、画面で「個人情報を書かないでください」と案内します。
5. **18 歳未満の文章は、安全の確認のためにもう一度 Anthropic に送ります。** 保護者の同意の画面で、このことを説明しています（`components/safety/AiAccessSetupView.tsx` の「送られるデータ」）。
6. **年齢は本人や保護者の申告です。** 身分証などで確かめてはいません。
7. **自分の AI をつなぐ機能（Phase 1）では、データの送り先を学習者が選びます。** 学習者が許可した AI アプリが、学習の記録を学習者の契約する AI の会社に送ります。Phase 2 から、レッスンごとの進み具合（確認問題に答えたか、正しかったか、など）も読めます。Rise Path はその会社と契約しておらず、送られた先での扱いを管理できません。許可の画面と利用規約でこのことを伝え、18 歳以上の人だけが使えるようにしています（許可の画面と、毎回の呼び出しで確かめます）。これが個人情報保護法の「第三者提供」にあたるか（本人の指示で本人のアプリに渡すと読めるか）は【要確認】です。アカウントを削除したときは、使ったことのある AI アプリの名前と日時だけを 3 年残します（Phase 4。第三者提供の記録にあたる場合に備えるためで、あたらなければやめます）。
8. **18 歳未満の人のレッスンの進み具合も、サーバーに保存します**（Phase 2）。AI の機能ではないので、AI 機能についての保護者の同意は確かめません。中身は、読んだところ、確認問題の答え、自己評価などで、自由に書いた文章はふくみません。MCP からは送りません（18 歳未満は MCP を使えないため）。ただし、保護者の同意があり、AI チューターに確認問題のことを聞いたときは、その問題の回答の回数、選んだ選択肢の ID、答えが表示されているかを Anthropic に送ります（上の「レッスン内の AI チューター」の行）。選んだ選択肢の ID は、安全の確認でもう一度送ります（「安全の確認」の行）。保護者の同意が要るかは【要確認】です（プライバシーポリシーの下書きの 7 の 2）。
9. **レッスンの記録は、本人が「学習の進み具合を消す」で消せます。** 1 つのレッスンの記録だけを、レッスンの終わりの「このレッスンを最初からやり直す」で消すこともできます（Phase 5）。どちらでも、XP の記録と学んだ日は消えず、アカウントを削除すると消えます。学習の履歴（題名をふくむ）は、アカウントを削除すると一緒に消えます（Phase 4）。アカウントを残したまま履歴だけを消す方法は、まだありません。消してほしいという求めには、運営者が DB で対応することになります【要確認: 手順】。
10. **有料プランのお支払いの記録は、アカウントを消しても残します**（Phase 3）。税と会計のためで、アカウントとのつながりだけを外します。何年残すかは【要確認: 税理士】です。Supabase でユーザーを消しても、Rise Path の DB と Stripe の記録は変わらないので、アカウントを消すときは、先に Stripe の契約をキャンセルします（`doc/brushup-2026/ai-access-plan.ja.md` 7.5）。Phase 4 のアカウントの削除は、続いている契約があると止まり、先に解約をお願いします（`server/services/accountDeletion.js`）。Stripe に送るのはアカウント ID だけですが、Stripe は支払いの画面で、カードの情報やメールアドレスを自分で受け取ります。プライバシーポリシーでの書き方は【要確認】です（プライバシーポリシーの下書きの 5 と 6）。
